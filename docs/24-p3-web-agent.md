# P3-W 联网查询与受限 Agent：首版实现与测试

状态（2026-09-30）：维基百科真实搜索、网页读取、Open-Meteo 天气查询及模拟模型的工具往返已通过测试。现已在本机 LM Studio 服务上复现和排查工具对话的输出限制；Brave API 密钥与真实麦克风体验仍待桌面验收。

## 使用方式

1. 启动 LM Studio 的本地服务并加载支持 Chat Completions 工具调用的模型。在设置面板的 LLM 卡片填入服务地址和模型 ID。
2. 在“联网查询”卡片勾选开关，选维基百科或 Brave Search。卡片中的开关、搜索范围和默认天气城市自动保存；文字查询可以在语音功能关闭时使用。LLM 地址与模型等其他设置仍由底部“保存语音设置”保存。
3. 维基百科无需密钥，适合百科知识；Brave Search 可查一般网页，需在卡片内单独保存 API 密钥，密钥进入 macOS 钥匙串，不进入桌宠设置文件和仓库。
4. 输入文字问题并点击“查询”。回答和来源分开展示；点击来源在默认浏览器打开。点击“停止查询”可取消本轮。
5. 语音功能启用且联网开关打开时，“上海今天天气怎样”“查询今天纽约的天气”会直接查天气；不说城市时使用已保存的默认天气城市，否则提示填写城市。明确搜索，以及新闻、股价、汇率、原神当前卡池等有时效的问题也进入联网路径。维基百科模式下如已保存 Brave 密钥，时效查询会自动改用 Brave；没有密钥会提示保存。普通聊天走无工具路径。语音朗读最终答案时会略过来源编号，来源仍在界面展示。

普通联网查询词发送到所选搜索服务，搜索结果与可选的页面摘录发送到配置的 LLM 服务。天气问题只把城市名称发送到 Open-Meteo 的城市查询和天气接口，由程序格式化带时间与来源的回答，无需 LLM 服务返回天气数据。用户应据来源核对重要事实；来源列表是检索结果，并不自动证明模型的每一句回答。

## 实现边界

| 层 | 当前行为 |
| --- | --- |
| 搜索 | `pet-web-retrieval` 调用维基百科 MediaWiki 搜索 API 或 Brave Web Search API，每次最多 5 条。中文查询选中文维基百科，其他查询选英文维基百科。 |
| 天气 | 自然语言天气问题直接调用 Open-Meteo 城市查询与 3 天天气预报。支持今天、明天、后天；无城市且无默认城市时提示补充，不猜测用户位置。回答列出温度、天气现象、降水概率、数据时间及来源。 |
| 页面读取 | 只读取本轮结果 URL；限制 HTTP(S)、公开域名、DNS 解析后的私有地址、跨站密钥重定向、重定向次数、响应类型与 2 MiB 响应体。正文最多 8000 字符。 |
| Agent | 每轮先搜索一次，再允许模型请求一次最多 3 个只读工具调用，随后获取最终回答。工具对话耗尽输出 token 时，改用 LM Studio 原生非推理回答路径对已取回的来源作简短摘要。整轮上限 45 秒。未知工具、非本轮结果 URL 和超预算调用被拒绝。 |
| 模型协议 | Agent 使用兼容 `/v1/chat/completions` 的非流式工具调用；普通对话保持既有 LM Studio 路径。工具结果以 `tool` 消息回传。 |
| 隔离 | 网页内容标记为不可信；工具执行权由 Rust 校验。开启“记住本次会话上下文”时，最多保留本次语音会话中最近 3 轮联网问答，用于理解“那下期呢”等追问；每轮重新检索，历史回答不作为事实证据。结束语音会话即清除，不写入长期记忆；来源与朗读正文分开。 |
| 取消 | 新文字查询或停止按钮使旧请求失效；语音沿用现有轮次取消机制。网络连接释放不代表 LLM 服务立即释放推理资源。 |

本机有网络扩展使用 `198.18/15` 与 `2001:2::/48` 作为公开域名的合成 DNS 地址；地址过滤针对这两个代理地址保留兼容，其余私有、回环及链路本地目标仍拒绝。字面 IP URL 均不作为页面目标。

头部点击和关键词唤醒若启用“开场白”，会在麦克风开始识别之前播放预录的“心事”，这段声音与后续问题无关；可在 Audio 卡片关闭。识别结果仍可能把“Rust”听成“RST”；对于同时含 RST 和“编程”的检索问题，查询路径会按 Rust 搜索。若工具对话报输出 token 上限，该轮不会把模型思考内容送给 TTS。

## 后续 Agent 规划

当前单 Agent 仅能搜索公开网页和读取本轮搜索结果，适合短问题。多来源、需要交叉核对的时效问题（例如游戏卡池）下一步可由调度器并行分派“搜索”和“来源核对”两个只读子 Agent，最终回答仍由主 Agent 汇总。每个子 Agent 应继承同一轮的来源白名单、最大调用次数、45 秒总时限和取消信号；不得访问本地文件、执行命令或自行扩展工具权限。上下文管理维持会话内短历史，时效事实逐轮重新查询并展示来源和查询时间。只有在真实多来源测试证明必要时才增加子 Agent，避免短问句额外耗时。

- 维基百科 live 测试：英文、中文查询和页面读取通过。
- Open-Meteo live 测试：上海城市解析及实时、逐日预报通过；自然天气问句可在模拟离线模型地址下返回来源。
- 语音对话适配器实测：注入“今天天气怎么样？”文字转写，不含“搜索”字样，在已启用联网且默认城市为上海时取得天气与来源；实际麦克风识别和 TTS 播放仍待桌面验收。
- 修复版 App 的桌面界面验证：勾选联网后立即显示自动保存，未点击底部“保存语音设置”即可完成“上海今天天气怎么样”查询；默认城市支持无城市名问句，退出重开后开关与城市仍保留。
- 模拟 Chat Completions 服务 + 真实维基百科：搜索结果、`fetch_page` 工具请求、工具结果回传和带来源回答通过。
- 本机 LM Studio 真实模型 + 维基百科：将语音识别文本“查询 RST 语言的编程特性”转为 Rust 检索后，返回带来源编号的相关回答；首次连接超时，重试通过。模拟工具对话输出触顶后，LM Studio 原生简短摘要回退通过。
- Open-Meteo 实测“查询今天纽约的天气”：中文“纽约”直查无结果，已映射到 `New York City` 并核对正确城市坐标；返回纽约预报。
- `cargo +1.95.0 test --locked -p pet-voice-session -p desktop-pet`：原有语音及桌面单元测试通过。
- 发布模式构建与本机 `.app` 临时签名检查通过；App 随本轮交付，资产包和测试数据留在忽略目录。实际麦克风、Brave 密钥和卡池信息仍需用户在桌面测试。

下一步桌面验收：分别用实际 LM Studio 模型尝试百科事实与有时效的问题；在 Brave 模式验证密钥、限流及断网提示；连续查询与停止各至少 30 次，确认无旧答案覆盖新问题；真实麦克风测试天气、新闻等自然问法、来源展示和 TTS 只读最终回答。维基百科对新闻与时效信息覆盖有限，不能以它的通过推断 Brave 或真实模型的质量。

天气数据使用 [Open-Meteo Forecast API](https://open-meteo.com/en/docs) 与 [Geocoding API](https://open-meteo.com/en/docs/geocoding-api)，界面和回答均署名 Open-Meteo。其[免费 API 条款](https://open-meteo.com/en/terms)限非商业用途；本地测试包按个人测试使用，未来商业发行需改用合适的商业方案或替换服务。
