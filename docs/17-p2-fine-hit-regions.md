# P2-06 细分点击区域与诊断

日期：2026-09-28。目标是在保留旧角色包头部／身体点击的同时，识别当前纳西妲正面模型中可见的脸、画面左侧手、画面右侧手、上半身和下半身，并在设置页提供点击结果与坐标供桌面校准。

当前设置面板已移除验收阶段的“点击区域检查”区；下文显示区域和坐标的操作是历史校准流程。命中多边形、真实点击与关系反馈继续工作。

## 依据与边界

- 原始 `model3.json` 没有 `HitAreas`，虽有 153 个 Drawable，但没有可直接套用的部位标签。本轮采用角色包内严格凸多边形；不改原始资源。
- P0 正面截图可辨认脸、两只手和躯干，坐标为初步目测值。下半身区域指正面裙装／腰腿附近，不代表背面的臀部；当前模型没有可准确标定的背面区域。
- 细分命中只做识别和诊断。脸沿用摸头反馈，其余细分区域沿用身体点击反馈；没有新增针对身体部位的专属表情或动作。
- 区域固定在顶部为原点的 5:6 角色视口，缩放后仍用归一化坐标。若以后手部位置随 Motion 大幅移动，需要用当前 Drawable 网格或随姿势变化的区域替代静态多边形。

## 实现

1. 协议 v4 将点击事件改为 `{region, point}`，坐标按视口千分比上报。宿主仍只把短按且松开时留在同一区域、窗口移动不超过 4 点、耗时不足 1 秒的操作视为点击；拖拽不记为点击。
2. 角色包 schema v3 新增 `interaction.regions`，允许 `face`、`left_hand`、`right_hand`、`upper_body`、`lower_body` 五个独立凸多边形，至少一个。命中顺序按上述顺序，再回退到旧的 `head` 和 `body`。悬停和点击穿透也覆盖新增区域。v1／v2 包继续按头部／身体工作。
3. 设置面板的“点击区域检查”显示当前角色支持的区域和最近一次点击的区域、横纵百分比。切换角色或宿主故障时清除旧记录。这里只保留最近一次点击，不写入养成存档。
4. 本地私有 v3 包位于 `artifacts/local/p2/nahida-hit-regions-v3/manifest.json`，包名“纳西妲 · 细分点击区域版”；示例格式在 `assets/demo/pack-template/manifest.v3.example.json`。该包沿用 P2-05 的 13 个表情与状态绑定。

## 待用户桌面校准

先退出其他 DesktopPet 测试应用，打开 `artifacts/local/p2/DesktopPet P2 Hit Regions.app`。若当前角色不是“纳西妲 · 细分点击区域版”，在“角色库”输入上述 v3 manifest 完整路径并导入切换。打开“点击区域检查”，分别短按脸、画面左手、画面右手、上半身和正面下半身，核对显示的区域与横纵坐标；再点击头发、手旁透明区与裙装外透明区，确认不会错误吞点击。拖动角色应不更新“最近点击”。在 50%、100%、150% 大小各抽查一次，并记录误判位置及坐标。

本轮自动化测试覆盖区域优先级、旧包兼容、非法多边形、协议序列化和旧反馈映射；屏幕上的真实命中边界仍需这轮手工校准。后续若静态区域在手部动作下误差明显，再评估 Drawable 网格随帧命中，而不是仅扩大多边形。

## P2-07a：区域目视初标（2026-09-28）

在上述五个细分区之上，协议 v5 与角色包 schema v4 增加画面左／右手臂、腹部、画面左／右腿、画面左／右脚，共 12 个细分多边形。命中时先检查脸、手、手臂、脚、腿、腹部，再检查上／下半身，最后回退至头部／身体。坐标仍为视口归一化值；区域名按画面左右，不按角色自身左右。v1–v3 角色包沿用原有行为。

本地私有角色包为 `artifacts/local/p2/nahida-calibration-v4/manifest.json`，示例格式为 `assets/demo/pack-template/manifest.v4.example.json`。校准包保留 13 个原始表情及已有状态／照料绑定，但不登记 `body_tap`，以免尚未校准的上／下半身区域点击产生无条件的害羞反馈。此阶段仅识别并展示区域，不对亲密度执行点击奖惩，也不启用 P2-07 的关系规则。

使用 `tools/p2/render-hit-overlay.py` 将私有 P0 正面截图与包内多边形合成到 `artifacts/local/p2/calibration/nahida-hit-overlay.svg`，并渲染 `nahida-hit-overlay-full.png` 供直接查看。根据这张图，已收紧双手区域，并把双臂初标移向可见手臂。脸、腿和脚大致落在预期画面位置；手臂与衣袖、腿与裙摆、宽泛上／下半身与装饰物仍有重叠。截图不能覆盖运动时的网格变化，以下桌面点击结果是修正多边形的依据。

先退出旧 DesktopPet 测试包，打开 `artifacts/local/p2/DesktopPet P2 Calibration.app`。若当前角色不是“纳西妲 · 区域校准版”，从角色库导入上述 v4 `manifest.json`。打开“点击区域检查”，依次短按脸、双手、双臂、腹部、双腿、双脚；核对最近点击的区域和横纵坐标。再试头发、上／下半身剩余可见部分以及角色外透明位置；拖拽不应更新最近点击。分别在 50%、100%、150% 大小抽查，尤其记录手臂与手、脚与腿、裙摆边界出现的错判及坐标。由这些结果调整包内多边形，再进入 P2-07b 关系规则实现。

### 内侧裙摆修正

用户确认头、脸、双手、双臂、双腿、双脚及原有上／下半身剩余区域表现正常；覆盖图 2 号红框左右环绕的内侧裙摆会回退为“身体”。原因是下半身剩余区域原先只有中央一个凸多边形，两侧落在其外。v4 包现在可用 `interaction.region_parts` 为已定义的细分区补充多个独立凸多边形，命中、悬停与点击穿透共用这些边界。纳西妲校准包在中央区域之外增加左右两片窄梯形，均返回 `lower_body`；手、臂、腿的优先级不变。使用 `artifacts/local/p2/DesktopPet P2 Skirt Calibration.app` 复点中央与左右内侧裙摆，再点贴近它们的手、腿及外侧翼状装饰。未校准前继续只显示诊断，不执行关系数值变化。
