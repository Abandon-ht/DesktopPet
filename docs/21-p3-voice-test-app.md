# 本机语音测试包

测试包：`artifacts/local/p3/DesktopPet Nahida Voice.app`。它使用独立的本机测试存档，启动时打开设置面板；角色资源、模型权重、互动 WAV 和 LM Studio 服务仍引用此开发机上的文件或服务，不随应用提交到 Git。

## 启动前

1. 退出旧版 DesktopPet，避免两个角色同时占用麦克风或扬声器。
2. 在 LM Studio 加载 `qwen/qwen3.6-35b-a3b`，开启 `http://127.0.0.1:1234` 的本地服务。测试包已预填这个地址和模型 ID。
3. 双击测试包。菜单栏应显示纳西妲头部线稿，Finder 中的应用图标应显示彩色头像；点击菜单栏图标，再选“角色与设置”可重新打开面板。首次访问麦克风时按系统提示授权。

## 语音链路

1. 在 **Audio** 确认“启用语音交互”已勾选、音量不为 0；在 **ASR** 先选择 `sherpa-onnx`，**LLM** 选择 LM Studio，**TTS** 选择 ZipVoice，然后保存。
2. 点击角色头部：预期先播放“心事”，再进入“聆听中”。说一句短中文，停顿约一秒；面板应依次显示识别文字、回复和播放状态。播放结束后会继续聆听，默认 8 秒不说话便回待机。再次点击头部可显式重启会话。
3. 将 **ASR** 改为 `sherpa-ncnn` 并保存。测试包已预填本机编译的 `sherpa-ncnn-offline` 和 2025-09-09 SenseVoice 模型目录；再点击头部并重复一句短中文，确认仍出现识别文字和语音回复。要调整线程数，在 sherpa-ncnn 高级设置修改。
4. 在 **KWS** 勾选“启用关键词唤醒”，此开关会自动保存。待 KWS 卡片显示“正在监听”后说“你好纳西妲”；预期与点击头部一样进入提示音和对话。若显示模型或麦克风错误，按卡片信息排查。也可试说“Hello Nahida”，但目前合成音测试未命中，英文仍需要真人录音校准。KWS 在播放和对话期间暂停，播放期间用点击头部打断。
5. 用“停止语音”结束当前会话；关闭 KWS 开关后，待机时麦克风应停止常驻监听。顶部界面语言可切换中英日韩；在 Audio 中填写 `MM-DD` 生日，喂食及主动陪伴的新语音按[互动语音说明](22-p3-localized-interactions.md)检查。

出现“语音初始化失败”时，先检查设置面板中的模型目录和 LM Studio 服务。若错误指出克隆参考 WAV 不存在，将 **TTS → 克隆参考 WAV** 设为本机现有文件，例如 `artifacts/voice/zh-CN/greetings/noon.wav` 的完整路径，再保存。更改语音素材目录后，本机 SQLite 存档中的旧路径不会自动改写；保存时会直接拒绝不存在的参考 WAV。出现“关键词监听失败”时，检查麦克风权限及 KWS 模型目录。测试包仅适用于此开发机；复制到其他电脑前须另行准备角色资源、模型、参考音频和 ncnn 程序。
