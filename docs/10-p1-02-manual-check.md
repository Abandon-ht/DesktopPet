此文保留 P1-02 交付时的操作与功能范围。当前开发包已更新至 P1-03，菜单入口为「角色与设置…」，新功能检查见 [P1-03 验收清单](11-p1-03-avatar-packs.md)。

日期：2026-09-19。代码及自动化验证已完成，用户已确认以下六项真实 UI 验收全部符合预期。当前开发版保持默认姿态，复用 P0 粗略命中和屏幕底边吸附；尚无自动眨眼/视线、头/身体反馈、角色包导入、大小设置、位置存档或他应用窗口吸附。

## 启动本地开发版

已准备本机开发包：`artifacts/local/p1/DesktopPet Dev.app`。包含两个 release 可执行文件和一个本地模型路径文本，**不复制角色资产**。这是未签名公证的开发包，不能当作 P6 发行包。

先退出旧 P0/P1 试件。在你用于测试的桌面（建议 Desktop 2）运行：

```sh
cd /Users/ncy/Projects/DesktopPet
open "artifacts/local/p1/DesktopPet Dev.app"
```

正常结果：菜单栏出现 **Pet**，角色出现；启动不弹出状态窗口。若没有角色，通过 Pet →「状态与帮助…」查看原因。关闭状态窗口只隐藏面板，Pet 菜单应继续可用。

如需重建或换本地模型路径，先退出开发版，再运行：

```sh
cargo build --release --locked -p desktop-pet -p avatar-host-2d
python3 tools/p1/package-dev.py "/绝对路径/角色.model3.json"
```

也可直接从终端启动，保留诊断日志（使用自己的模型路径）：

```sh
DESKTOPPET_MODEL="/绝对路径/角色.model3.json" \
  target/release/desktop-pet 2>artifacts/local/p1/app-manual.log
```

当前未做单实例拦截；不要同时启动多个开发版。模型在进程启动时读取，修改路径后需退出再启动。「重试连接」用于解除重启预算耗尽后的暂停，不负责选择新模型。

## 本轮只需确认六项

| 操作 | 预期 | 结果 |
| --- | --- | --- |
| 启动，随后在原来的文本编辑器继续输入 | 角色显示，不主动抢走键盘焦点；默认姿态及透明边缘正常 | 用户确认通过 |
| Pet → 隐藏角色 → 显示角色，重复 5 次 | 隐藏后角色消失且不截获点击；显示后恢复；状态面板按钮同样有效 | 用户确认通过 |
| Pet → 状态与帮助，关闭面板，再打开 | 读到「已连接」；关面板后角色和托盘继续运行 | 用户确认通过 |
| 正常拖拽，再按住拖动至少 10 秒 | 拖动可用；松手后稳定；没有因长拖拽超时而消失重启 | 用户确认通过 |
| 在透明区域点击其他应用 | 点击落到下面应用，不被角色窗口吞掉 | 用户确认通过 |
| Pet → 退出 DesktopPet | Pet 和角色一起消失，不残留宿主进程 | 用户确认通过 |

结束后可在终端检查（退出后应没有输出）：

```sh
pgrep -fl 'desktop-pet|avatar-host-2d'
```

如果托盘无法操作，先用活动监视器结束 **desktop-pet**；宿主应在管道断开后退出，最迟由 8 秒租约超时清理。仅在宿主仍未退出时结束 **avatar-host-2d**。请记录当时操作和状态信息；不要直接把显示失败视为资产不兼容。

可直接反馈：`1–6 均正常`，或写明失败编号、表现、是否能够通过托盘退出。无需本轮执行 100 次交互、三类他应用 AX 吸附、睡眠或拔插屏，它们仍在 P1-04 至 P1-06 验收范围。
