## 本步实现

- `avatar-pack` 固化 v1 目录包格式，JSON Schema 位于 `schemas/avatar-pack-v1.schema.json`，配置模板位于 `assets/demo/pack-template/`。旧规划草案不是可导入格式；不进行隐式迁移，非 v1 明确报错。
- 从设置面板粘贴 `manifest.json` 的绝对路径导入。复制至应用私有角色库，校验暂存副本后原子重命名，目录名含 SHA-256 内容摘要。相同内容重复导入复用；检测已导入副本被修改。源角色资源不修改。
- 候选角色先在隐藏的独立宿主中加载。模型损坏、映射参数不存在或加载超时时，保留已运行的角色；候选成功后退出旧宿主并同步显示状态与大小。稳定运行时只有一个宿主，切换验证期间允许短暂同时存在两个。
- 大小支持 50%–150%，基准视口为 500×600 逻辑点。成功选择的角色路径和大小通过临时文件加 rename 保存到应用私有设置；重启恢复。位置恢复仍在 P1-04。
- 角色包提供头/身体凸多边形和表情映射；命中坐标随视口缩放。短按松开后上报语义 Hit，主程序 PetCore 按能力选择反馈，再发回宿主播放。拖拽开始、隐藏、缩放清除待处理点击；宿主拖拽中忽略迟到反馈。
- 点击判定：同一区域松开、按住少于 1 秒，且窗口相对按下位置的移动不超过 4 逻辑点。不要求用表情代替肢体动作。表情支持配置持续时间、源文件淡入淡出，结束后恢复默认参数；参数映射仅存在于包和适配器中。

## v1 约束

| 项目 | 当前限制 |
| --- | --- |
| 输入 | 目录包的 manifest.json；不接受 zip，不执行脚本 |
| 文件 | 只接受 JSON、PNG、moc3；最多 1024 文件、2048 总目录项、12 层目录 |
| 大小 | 总文件 128 MiB；单 JSON 1 MiB，其他单文件 32 MiB |
| 路径 | 必须包内相对路径；拒绝绝对路径、`..`、反斜杠与包内符号链接 |
| 贴图 | 1–32 张，PNG，边长 ≤8192；包中所有 PNG 的预计 RGBA 总量 ≤128 MiB；拒绝重复引用 |
| 模型 | 加载后最多 2048 网格、500,000 顶点；在受超时保护的独立宿主内解析 moc3 |
| 命中 | 头/身体各 3–32 个顶点，严格凸多边形，坐标 0–1；头部优先 |
| 表情 | 每项 100–5000 ms，源淡入/淡出各 0–2 秒；参数必须在模型中存在 |
| 授权 | unverified / licensed / original；unverified 不得标为可分发，应用不代为确认授权 |

Schema 描述基本数据形状；文件存在性、路径边界、字节长度、凸性及资源预算由 Rust 进一步校验。网格预算在 moc3 解析之后检查，不宣称可在第三方解析器分配内存之前限制全部内存使用。目录复制不是网络下载器；损坏 moc3 可以进入结构合格的库，但在宿主验证失败后不能替换当前角色。

应用数据位于 macOS `~/Library/Application Support/dev.desktoppet.alpha/`：`packs/` 保存导入副本，`preferences.json` 保存版本化配置。角色库和本地测试资源不入 Git。当前未提供删除按钮；手动改动库内容后需要重新导入/修复，不能把摘要目录当作可编辑源文件。

IPC 增加 avatar、poll 和 SetScale，保持 v1 信封校验。可见时最多 10 Hz 轮询语义事件，隐藏时 1 Hz；单批最多 32 个 Hit，满时丢弃后续点击，不积累无界反馈。渲染、插值、命中采样仍在宿主本地。反馈去重覆盖同会话最近 128 个控制请求，不能作为 P2 的持久化业务去重。
