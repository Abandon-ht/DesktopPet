# Windows W1 基础桌宠验收

历史 W1 本地测试目录（相对仓库根目录）：`.\artifacts\local\windows-stage1\DesktopPet`。

运行 `start-test.ps1`，或执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\artifacts\local\windows-stage1\DesktopPet\start-test.ps1
```

脚本隐藏控制台窗口并打印日志路径；设置面板自动显示。没有角色路径环境变量也应能启动。若你已在终端设置 `DESKTOPPET_MODEL`／`DESKTOPPET_RESOURCES`，先使用未设置这些变量的新终端测试自动发现。

数据保存在 `artifacts/local/windows-stage1/data`；日志是 EXE 同目录的 `desktop-pet-日期时间.log`。保留整个目录结构，不要只拷贝主 EXE，也不要单独双击宿主。该目录是本地开发测试包，尚无安装程序。

按以下顺序检查；每项反馈“通过／失败／无法测试”即可。失败时附对应时间、现象和日志文件名。

| 项目 | 操作与预期 |
| --- | --- |
| 自动启动 | 设置状态进入 `ready`，`host_pid` 有值，角色出现；不再出现“未配置角色”或循环 `recovering`。 |
| 透明与焦点 | 在白色、深色及有文字的窗口前观察，无不透明矩形、黑边或明显透明错误。关闭设置后，在记事本输入文字，托盘隐藏再显示角色；显示和悬停应不改变键盘焦点。点击角色允许它获得焦点。 |
| 真实穿透 | 在角色窗口空白处点击下层记事本／浏览器，光标或按钮应响应。移回角色并点击头、脸、手，应有对应表情或养成反馈。请同时试几次快速移入后点击，记录漏接或误吞。 |
| 拖拽 | 从角色交互区域按下拖动后松开，能跟随并停止；从下层应用开始拖选、再经过角色时不应被角色抢走。按住拖动超过 10 秒，确认没有宿主超时／重启。 |
| 大小与位置 | 设置 50%、100%、150%，透明区和角色命中仍对齐；拖到离屏幕底部约 12 逻辑像素以内松手，脚底吸附工作区底部。放在屏幕中部松手应保持原处。 |
| 托盘与存档 | 隐藏、显示、打开设置、退出均正常。移动角色后退出再启动，位置与大小恢复；任务管理器中退出后没有本次宿主残留。 |
| DPI／多屏 | 有条件时跨 100%／150%／200% 显示器拖动，观察大小、命中、位置和任务栏边界。副屏放在主屏左侧／上方也应可用；拔掉角色所在副屏后回到主屏。只有单屏时标为无法测试。 |
| 锁屏／休眠 | 锁屏再解锁、休眠再唤醒后仍能显示、拖动和点击，无不断重试或永久穿透。 |
| 宿主恢复 | 从设置读取本次 `host_pid`，在任务管理器只结束该 PID；主程序应重新连接并恢复角色。先隐藏角色后再结束宿主，恢复期间应保持隐藏。 |
| 目录迁移（可选） | 完全退出后，将整个 `DesktopPet` 目录复制到另一个含空格／中文名称的目录，再用新目录的脚本启动。无需重新指定角色和内置模型路径。隔离数据目录仍共用原测试数据。 |

W1／W2 功能已由用户确认测试正常。W1 保留为回归清单；他应用观察器与语音现已接入，混合 DPI、长期运行和 Windows Brave 凭据保存仍需专项验证。

```text
多屏、锁屏／休眠、宿主恢复：通过／失败／无法测试

对应日志文件名：
```
