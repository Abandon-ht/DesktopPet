## P1-01 已实现契约

- `pet-protocol` 仅依赖 serde：角色/桌面能力、权限状态、类型化命令和事件。JSON 使用显式 `type`/`payload`，未知命令、未知字段和未知语义值报错。
- `PetCore::update(Event) -> Vec<Effect>` 是无 I/O 的确定性状态归约；外壳按顺序投递事件并执行效果，使用 `state()` 读取 UI 投影。没有引入养成、数据库或语音依赖。
- 支持 Idle、Dragged、Perched；头/身体点击由能力决定语义反馈，不支持的反馈立即无操作，不产生等待。拖拽期间不接受点击反馈。
- 外部吸附只有在用户启用、授权、平台可观察且可绝对定位、角色 ready 且显示时才启用。权限/能力丢失立即禁用并解除现有外部吸附。宿主负责目标关闭/最小化等检测并报告解除。
- `visible` 保存用户意图，并非已收到原生窗口显示确认。加载故障隐藏宿主但保留意图及错误；恢复 ready 后重新同步。`Stopped` 清空宿主能力与权限，避免重启沿用旧探测结果。
- Quit 对核心实例是终态，晚到的 Ready 或显示请求不能恢复角色。隐藏效果先于动画取消；Quit 直接发 Shutdown。
- AvatarPort／DesktopPort 目前只规定非阻塞发送接口。`Ok` 表示接受投递，并不表示原生执行成功；执行故障需外壳转换为事件。外壳可绕开 PetCore 直接调用 DesktopPort 的隐藏/退出命令。

当前能力位只覆盖核心会消费的角色点击反馈；gaze、blink 等能力及 LoadPack、位置/大小命令将在对应适配器落地时扩充，不预先声明支持。

### P1-01 完成时的接入约束

P1-01 完成时，P1-02 需要将 P0 已验证的 256 KiB 有界行协议、握手、session/sequence/request_id 校验、心跳与 EOF 退出迁移到正式传输层。`pet-protocol` 的 `PROTOCOL_VERSION` 是协议版本常量，语义 DTO **不是完整 IPC 信封**；P1-02 的传输实现见下文。

核心假设事件来自当前宿主会话且有序。Supervisor 必须丢弃旧会话事件，连接终止后先发 Stopped，再接收新会话事件；不能用当前核心替代传输层时序校验。

主进程外壳必须实现不依赖业务队列的隐藏/退出入口；宿主必须独立实现父进程丢失退出、拖拽锁、输入穿透切换和本地位置/动画更新。目前接口和效果顺序的测试不证明这些运行时行为已经完成。

## P1-02 应用与独立宿主（2026-09-19）

以下记录该步骤交付时的范围；当前角色导入、大小与反馈能力以 P1-03 为准。

代码和自动化验证完成，用户已确认六项真实 UI 验收全部符合预期，P1-02 通过。[启动及六项人工检查](10-p1-02-manual-check.md)。

- `apps/desktop`：Tauri 2.11.5 托盘与本地状态面板；显示/隐藏/重试/退出。面板关闭后常驻；模型缺失或三次失败后保留托盘和错误说明。当前由环境变量或开发包内的路径文本指定模型，角色包导入仍属 P1-03。
- `apps/avatar-host-2d`：独立 winit/Mocari 0.3.1 宿主，复用 P0 透明合成、预检和粗略输入代码。首次窗口隐藏，主进程握手后同步可见性；恢复时不会先闪出隐藏的角色。移除 P0 表情轮播、截图库和无界帧耗时数组，当前只渲染默认姿态；隐藏时暂停绘制和全局鼠标采样。
- `crates/pet-ipc`：从 P0 监督实现派生正式传输层；256 KiB 行上限、握手、session/sequence/request_id 校验、超时回收与 60 秒三次失败预算。桌面命令经主线程实际应用后返回 `result`，payload 的 `accepted` 表示执行接受/拒绝；未实现能力明确拒绝。近 128 个桌面 request_id 去重，同 ID 不同参数报错；当前命令均幂等，此缓存不能替代 P2 事务去重。
- 主程序在专用线程运行监督和 PetCore；隐藏/退出由独立原子状态和容量为 1 的唤醒通路传入，不排在业务效果队列后。普通请求超时上限 2 秒，启动握手 5 秒；这些不是零延迟承诺。角色反馈能力暂为空，不虚报头/身体反馈或 AX 能力。
- 原生宿主检测 EOF 后退出；独立 8 秒租约线程处理父进程失联和原生事件循环卡住。正常退出先隐藏，再确认协议和回收子进程。业务线程 panic 也经 RAII 回收宿主。
- P0 源码保持不动作为验证基线。本步有意从已验证试件派生原生基础模块；后续以正式宿主为产品实现，P0 仅保留回归用途。正式包不依赖 `tools/p0-*` crate。

验证：全工作区 54 项 Rust 测试、Clippy 和格式检查通过。真实原生宿主隐藏窗口五组生命周期检查通过（含真实父进程被杀）；主程序队列过载、崩溃恢复、预算耗尽、手动重试和缺模型降级由无 GUI 假宿主测试覆盖。日志和本地开发包位于被忽略的 `artifacts/local/p1/`，角色文件未复制入仓库。

上述六项已获用户确认通过。签名公证/单实例/正式安装路径仍属 P6；真实点击反馈、位置和大小设置在 P1-03/P1-04 落地，不据本步宣称整个 P1 已完成。
