# P1-06 alpha 桌面验收

开始日期：2026-09-24。P1-02、P1-03 已通过用户桌面验收；P1-04 的动画、点击表情与可调视线范围已确认；P1-05 的坐窗位置、跟随与高度微调已确认，但跟随仍有可感知滞后。以下项目需要实际桌面结果及日志，不能用单元测试替代。

## 采集方法

先从菜单栏退出所有旧版，在项目根目录打开终端运行：

```sh
python3 tools/p1/run-p1-06.py --label idle
```

启动器默认运行固定的 `artifacts/local/p1/gaze-range/DesktopPet Gaze Range.app`，自动在被 Git 忽略的 `artifacts/local/p1/p1-06/` 下建立本次目录，保存 `app-stderr.log`、每 5 秒一次的 `resource-samples.csv`、包的哈希与版本信息，以及正常退出后更新的 `render-metrics.json`。每组测试可重新运行并更换 `--label`；结束时使用菜单栏 **Pet → 退出 DesktopPet**，让宿主写出最后的帧指标。不要同时启动多份桌宠，也不要在一次验收期间重建或重签测试包。

如需在已获辅助功能权限的坐窗包上做窗口测试，单独运行：

```sh
python3 tools/p1/run-p1-06.py --label window-snap --app 'artifacts/local/p1/ax-seated-snap/DesktopPet P1-05 Seated Snap.app'
```

这两包是不同的应用身份。坐窗包保留此前已授权的窗口功能；新视线包无需为普通视线/交互测试开启辅助功能权限。两次运行分别记录，不能把旧包的窗口结果当作新包的集成结果。

## 测试清单

| 编号 | 操作 | 需要记录的结果 |
| --- | --- | --- |
| 01 空闲性能 | 默认 100% 大小，关闭启动时的设置面板，显示角色并静置 5 分钟；不移动鼠标，最后从菜单栏正常退出。 | 角色是否持续动画、是否闪退；日志中的 `present_interval_ms_p95`、`cpu_submit_ms_p95`，以及 CPU/RSS 趋势。如方便，可另记“活动监视器 → 能源”中两个进程的能源影响；采集器本身不测能耗。帧间隔 p95 ≤ 33.3 ms 是目标，日志只是 present 调用间隔，不等于真实屏幕帧率。 |
| 02 交互稳定 | 按已有 `artifacts/local/p1/p1-04-interactions.csv` 做 100 次短按头、短按身体、拖拽、透明区点击及快速移入拖拽；按清单切换 50%、100%、150% 大小。 | 每次在 CSV 的“结果/备注”列填写正常或异常；特别记录漏接、误吞下面应用的点击、拖拽卡住和角色消失。不能以脚本生成的 100 行代替实际操作。 |
| 03 Spaces 与全屏 | 将角色移到第二个桌面空间，来回切换；打开一个全屏应用再返回；快速连续拖动角色 20 次。 | 角色是否仍可找到、能否拖动和退出；焦点是否异常抢占；全屏期间是否显示按实际情况记录，不预设所有 Space 都可见。 |
| 04 睡眠恢复 | 显示角色时使 Mac 睡眠至少 1 分钟，唤醒后等 30 秒，再移动鼠标、点击角色、隐藏/显示并退出。 | 是否卡住、重启、位置跳动、点击失效；记下睡眠与唤醒的大致时间。 |
| 05 外接屏与工作区 | 有外屏时，将角色拖到外屏，测试跨屏拖拽、拔掉外屏再接回；也可切换 Dock 自动隐藏。无外屏则标“未测”。 | 角色是否退回主屏可见区域、尺寸/位置是否异常、显示/隐藏是否仍可用；记下每块屏的缩放设置。 |
| 06 三类窗口吸附 | 用已授权的坐窗包，分别吸附 Finder、浏览器和编辑器窗口；每类都移动、缩放、切换焦点、最小化或关闭。 | 哪一类成功、跟随是否有滞后/跳动、切换后是否解除、最小化/关闭后是否回到安全位置；记下应用名和大致时间。 |

可以先完成 01、03、04，把每项的“正常/异常/未测”和日志目录告诉我；02、05、06 可以分批。分析时会按日志时间对照操作，区分真实观察、宿主事件、CPU/内存采样与渲染指标。指标没有 GPU 完成时间或实际屏幕刷新率，不能单凭它宣称性能 Gate 通过。
