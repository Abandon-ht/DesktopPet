| 项目 | 操作与预期 |
| --- | --- |
| 目标选择 | 设置勾选“其他应用窗口吸附”，再点击浏览器或记事本，使目标成为前台窗口。拖动角色前等约半秒。Windows 无需 macOS 辅助功能授权。 |
| 顶边吸附 | 目标窗口不要最大化，先留出顶边上方空间。将角色脚底或身体中线拖到目标顶边附近（约 24 逻辑像素内）并松手。角色应以身体中线坐在顶边，下半身叠入窗口；不会移到应用的侧边。 |
| 跟随与解除 | 拖动／缩放目标窗口，角色跟随顶边；最小化、关闭或切换到其他应用时解除并保持在屏幕工作区。拖走角色也可解除。目标应用本身不能被桌宠移动。 |
| 开关与保存 | 关闭吸附开关后普通拖拽、屏幕底部吸附仍可用；正常退出再启动后开关、角色位置和大小恢复。 |
| DPI／多屏 | 有条件时跨不同缩放的显示器移动目标，检查角色位置和命中是否对齐。无多屏时标记无法测试。 |
| 手动语音 | 语音设置应为 Ollama 和上述别名，语音总开关保持开启。关闭设置后短点头部并说一句话，确认 `listening → recognizing → thinking → synthesizing → speaking → idle`，识别文字、中文回复和声音正常。首次请求可能较慢。 |
| 停止／打断 | 录音、等待回复和播放阶段分别点击停止，确认能恢复空闲；随后再次发起能成功。不要同时运行 W1 和 W2，以免争用麦克风／扬声器。 |
| 关键词唤醒 | 已保留 W1 的 KWS 设置；若启用，使用设置中已有唤醒词测试。确认不会被自身播放持续唤醒。 |
