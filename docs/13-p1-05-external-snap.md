# P1-05 他应用窗口吸附

开始日期：2026-09-24。已加入实验开关和 macOS AX 前台窗口读取；用户已能在本地测试包中勾选开关，但实际吸附效果未通过桌面验收。P1-04 的眨眼、视线和点击表情已获用户确认；100 次交互和多屏等仍待验收。

## 2026-09-24 实机反馈与需求修订

用户已能勾选实验开关，但实际效果尚未通过：角色脚底与目标窗口上沿之间出现可站立的视觉间隙；拖动目标窗口时，角色没有随窗口移动。现有“脚底贴合窗口顶边”的规则与目标效果不符，不能据此认定 P1-05 验收通过。

目标效果以用户提供的第二张参考图为准：目标窗口的上沿穿过角色身体约一半的位置，角色下半身视觉上叠在窗口内，呈现坐在窗口上的感觉。此阶段要求调整位置关系，不要求新增坐姿动作。窗口接触高度必须能按角色分别配置，不得直接复用屏幕底部吸附使用的脚底锚点；角色缩放后仍须保持相同的相对接触位置。

吸附成功后需要绑定具体目标窗口，而非只记住松手时的坐标。拖动或缩放该窗口时，角色应保持相对水平位置及配置的垂直接触高度并连续跟随。关闭、最小化或无法再观察目标时，按可预测的规则解除吸附并回到安全位置。须在界面或诊断记录中区分“已吸附到窗口”与“回退到屏幕边缘”，以免仅凭视觉重合误判。

用户确认：角色保持最前端的现有逻辑优先；切换到其他窗口或应用时解除吸附跟随，不随旧窗口继续移动。每个角色的窗口接触高度需可在设置面板微调，并在切换角色或重启后恢复各自的设置。角色包可提供默认高度，但本地微调不应改写导入的角色资源。

接下来的实现和验收以这组要求为准。验收应分别检查吸附成功后的窗口移动/缩放跟随、焦点切换后的解除、角色独立高度设置及重启恢复。

## 已完成的第一步

`apps/avatar-host-2d/src/external_snap.rs` 定义有身份的目标窗口和独立吸附状态。用户拖拽松开时，角色脚底或窗口接触线距合法目标顶边 24 逻辑点以内且水平范围重叠即可吸附；该容差覆盖模型脚底与窗口之间的小视觉间隙。吸附后窗口顶边对齐独立接触线，记录沿目标窗口的水平比例，目标移动或缩放后可重算角色位置。自身进程、已最小化窗口、错误几何和未获授权均被拒绝。

目标丢失、窗口身份变化、最小化或授权撤销时立即清空吸附状态。上述策略由确定性单元测试覆盖。

## 实验接入

- 设置面板增加“他应用窗口吸附”开关，默认关闭。用户主动开启时宿主先读取 `AXIsProcessTrusted`；没有授权则调用 `AXIsProcessTrustedWithOptions` 请求系统显示授权提示，并拒绝本次开启。用户完成系统授权后需再次点击开关；屏幕底部吸附继续可用。
- 独立线程每 250 ms 读取当前前台应用的焦点窗口，只取进程、窗口身份、位置、大小和最小化状态；每次 AX 消息设置 0.2 秒超时。渲染线程读取最新快照，不直接执行 AX 查询。拖拽角色导致宿主临时成为焦点时，工作线程继续观察此前的目标；焦点真正切到另一窗口或应用则解除吸附。拖拽松开时按上述规则吸附，已吸附时按最新几何跟随。
- 手动关闭、隐藏、拖动角色会解除吸附；目标丢失、最小化或权限撤销时回落到当前工作区底部。角色始终维持原有最前端显示策略。
- 当前尚未接入 `AXObserver` 通知，采用 250 ms 查询；部分应用可能不提供焦点窗口或所需属性。尚未验证实际跟随精度、跨 Space 和性能，不能标记 P1-05 通过。

早期授权检查曾返回 `ax_trusted=false`：旧本地包把主程序和渲染宿主作为不同进程运行，且多个不同文件名的测试包共用同一个 `CFBundleIdentifier`。系统列表显示某个测试包“已开启”并不能证明当前运行的进程获权。文件选择器也不能可靠选择包内的裸宿主可执行文件。现已将宿主改成独立的嵌套 `.app`，并给每个本地开发包生成独立标识与对应的宿主标识；外层和嵌套包按顺序做本地临时签名。用户已确认旧权限测试包中的开关可正常勾选；新版坐窗测试包仍需单独授权并验收实际效果。

开发包使用临时签名。重建或重新签名可能改变系统用于识别授权对象的代码身份；一次人工验收期间应固定同一个包，不要在授权后重建。不要一次选择多个旧测试包。

## 新版桌面验收

新版测试包与旧的权限测试包使用不同应用身份。先完全退出旧版，只从 `artifacts/local/p1/ax-seated-snap/DesktopPet P1-05 Seated Snap.app` 打开；如系统要求，分别为这一个主应用和包内宿主授予权限，退出并从同一路径重开。不要在这次验收中重建或重新签名该包。

1. 在 Finder 打开普通窗口并使其成为当前窗口，等待约一秒；开启实验开关，将角色脚底或身体接触线拖到窗口顶边附近松开。角色应立即移到“窗口上沿穿过身体约一半”的位置，而非脚底悬在上方。
2. 拖动 Finder 窗口并调整宽度，角色应保持配置的垂直接触高度和相对水平位置跟随。点击另一个窗口或应用后，角色保持最前端但解除旧窗口的跟随。
3. 将设置中的窗口接触高度从 50% 调到 40%，再次吸附应更深地叠入窗口；重启后数值应保留。切换另一角色时应显示该角色自己的数值，切回原角色后原数值仍在。
4. 最小化或关闭已吸附的窗口，角色应解除吸附并回到安全位置。记录未成功吸附、突然跳动和焦点切换后继续跟随等异常。

此项仍须用户实机确认；几何和配置单元测试不能代替桌面跟随验收。

## 后续实现顺序

1. 接入 `AXObserver` 移动、大小、最小化和销毁通知，以低频查询补足不发送通知的应用；稳定窗口身份与权限撤销后的 UI 状态。
2. 验证至少三类应用窗口，以及拒绝/撤销授权、关闭/最小化、Space 和多屏行为。结果写入此文档后才能标记 P1-05 通过。
