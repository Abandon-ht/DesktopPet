# P1-05 他应用窗口吸附

开始日期：2026-09-24。当前只完成宿主侧纯规则，功能尚未接入真实窗口，也未开放应用开关。P1-04 的人工验收仍待进行。

## 已完成的第一步

`apps/avatar-host-2d/src/external_snap.rs` 定义有身份的目标窗口和独立吸附状态。用户拖拽松开时，仅在角色脚底距合法目标顶边 12 逻辑点以内且水平范围重叠时吸附；记录沿目标窗口的水平比例，目标移动或缩放后可重算角色位置。自身进程、已最小化窗口、错误几何和未获授权均被拒绝。

目标丢失、窗口身份变化、最小化或授权撤销时立即清空吸附状态。上述策略由确定性单元测试覆盖；目前宿主尚未用 AX 取得目标，也未将这些规则接入实时拖拽，所以没有对实际应用吸附的用户可见行为。当前 `SetExternalSnapEnabled(true)` 仍会被宿主拒绝，避免误报能力。

## 后续实现顺序

1. 在 macOS 宿主读取 AX 授权状态和候选窗口身份/几何；拒绝授权时保留原有屏幕脚底吸附。
2. 接入窗口移动、大小、最小化和销毁观察，并以低频查询补足不发送通知的应用；在渲染线程之外处理可能阻塞的 AX 调用。
3. 将权限状态与用户开关接入应用；启用、撤销和隐藏时同步解除吸附。不得弹出循环授权提示。
4. 验证至少三类应用窗口，以及拒绝/撤销授权、关闭/最小化、Space 和多屏行为。结果写入此文档后才能标记 P1-05 通过。
