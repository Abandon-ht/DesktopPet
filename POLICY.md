# Project use and copyright / 项目使用与版权

Contributors and users must not use this project to create or distribute sexualized content involving minors or minor-presenting characters.

禁止使用本项目制作或传播涉及未成年人或明显幼态角色的色情、性化内容。

This restriction applies to code, character packs, voice packs, screenshots, recordings, and derived distributions. Contributors must not submit such material to the repository or its Releases. Maintainers may remove violating material and reject related contributions.

该限制适用于代码、人物包、语音包、截图、录屏以及衍生发布物。贡献者不得向仓库或 Release 提交此类内容；维护者可移除违规材料并拒绝相关贡献。

## Copyright reports / 版权投诉与删除

The application code and third-party assets have separate rights. A file being publicly available, or this project being non-commercial, does not by itself grant redistribution rights. Sources and known license status are recorded in [docs/ASSETS.md](docs/ASSETS.md). Where no license can be verified, the status is stated as unverified rather than presented as permission.

程序代码与第三方资源的权利归属不同。资源可以在网上公开访问、项目不以商业为目的，均不自动构成再分发授权。来源及已知许可状态记录于[资源清单](docs/ASSETS.md)；无法核实的许可会明确标为“未核实”，不会写成已获授权。

If you own rights to material in this repository, a Release, or a distributed app and believe its use is unauthorized, please open a [GitHub issue](https://github.com/Abandon-ht/DesktopPet/issues/new) with the file or Release URL, proof or explanation of your rights, and the requested remedy. Avoid posting private contact details in a public issue; you can request a private follow-up there. The maintainer will review the report and remove or replace affected material when appropriate. You can also use [GitHub's copyright claim process](https://docs.github.com/en/site-policy/content-removal-policies/submitting-a-copyright-removal-request) for a formal request.

如你认为仓库、Release 或应用包中的素材侵犯你的权利，请通过 [GitHub Issue](https://github.com/Abandon-ht/DesktopPet/issues/new) 提供文件或 Release 链接、权利证明或说明及希望采取的措施。请勿在公开 Issue 中留下私人联系方式；可以提出私下后续联系。维护者会核查并在适当情况下删除或替换相关资源。正式投诉也可使用 [GitHub 版权删除流程](https://docs.github.com/en/site-policy/content-removal-policies/submitting-a-copyright-removal-request)。
